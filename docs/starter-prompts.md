# Starter prompts

These prompts map to real CuteNote tools. Replace example URLs and IDs with content you are authorized to use.

| Task | 中文 | English |
| --- | --- | --- |
| Video to long image | `把这个公开视频做成一张中文长图：https://example.com/video/123` | `Turn this public video into an English long image: https://example.com/video/123` |
| Web page to Markdown | `把这个公开网页整理成详细 Markdown 笔记：https://example.com/article` | `Convert this public web page into a detailed Markdown note: https://example.com/article` |
| Long text to mind map | `请把我附上的长文本整理成脑图，并导出 PNG。` | `Turn the long text I attached into a mind map and export it as PNG.` |
| List notes | `列出我最近的 CuteNote 笔记，不要新建笔记。` | `List my recent CuteNote notes without creating a new note.` |
| Read a note | `读取这篇已有笔记的内容：<note-id>。` | `Read the contents of this existing note: <note-id>.` |
| Re-export | `把已有笔记 <note-id> 重新导出为 PNG，不要重新生成。` | `Re-export existing note <note-id> as PNG without regenerating it.` |
| Refresh expired link | `上次的链接过期了，请为 <note-id> 重新生成 Markdown 下载链接。` | `The previous link expired. Create a fresh Markdown export link for <note-id>.` |
| Check installation safely | `检查 CuteNote 工具是否安装好了，但不要创建测试笔记。` | `Check whether CuteNote tools are installed, but do not create a test note.` |

For authorization, say: `连接我的 CuteNote 账号；需要授权时打开浏览器，不要让我粘贴任何密钥。` / `Connect my CuteNote account using browser authorization; do not ask me to paste any credential.`
