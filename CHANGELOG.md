## [1.0.0] - source baseline

- Defined the first versioned contract for the remote MCP server, canonical Skill, Codex plugin, Claude plugin, and WorkBuddy connector.
- Added the five-tool workflow for note creation, polling, retrieval, and export.
- Added OAuth 2.1 with browser authorization code + PKCE documentation and public integration safety checks.
- Added bilingual public documentation, compatibility records, and marketplace review materials.
- Added private vulnerability reporting guidance, weekly npm dependency update proposals, and a least-privilege validation workflow with commit-pinned GitHub Actions.

This entry records the release-ready source baseline at [JoeyMonki/cutenote-integrations](https://github.com/JoeyMonki/cutenote-integrations). The public source repository is live. See [`publication.json`](publication.json) for whether the matching GitHub Release has completed; this changelog does not claim remote publication early. npm and marketplace publication are separate.
